# מעקב הוצאות

אפליקציית ווב פשוטה למעקב אחר הוצאות אישיות, בעברית.

## פיצ'רים
- הוספה, עריכה ומחיקה של הוצאות (סכום, תאריך, קטגוריה, תיאור)
- סיכום חודשי ופירוט לפי קטגוריה
- גרפים: התפלגות לפי קטגוריה ומגמה של 6 חודשים אחרונים
- ייצוא ל-CSV (נפתח בעברית תקינה באקסל)
- הנתונים נשמרים בדפדפן (localStorage) – ללא שרת

## הרצה
```bash
npm install
npm run dev      # שרת פיתוח
npm test         # בדיקות
npm run build    # בנייה לפרודקשן (לתיקייה dist)
```

## טכנולוגיות
React 18, Vite, Recharts, Vitest.
