# מעקב הוצאות

אפליקציית ווב פשוטה למעקב אחר הוצאות אישיות, בעברית.

## פיצ'רים
- הוספה, עריכה ומחיקה של הוצאות (סכום, תאריך, קטגוריה, תיאור). טופס ההוספה בראש הדף
- הוצאות קבועות שחוזרות כל חודש, עם אפשרות להפסיק אותן מחודש מסוים
- תקופות: חודש, 6 חודשים או שנה, עם השוואה לתקופה הקודמת, ממוצע חודשי והחודש היקר ביותר
- סינון לפי קטגוריה אחת או יותר, שמשפיע על הסכום, הגרפים והרשימה
- גרפים: עוגה לפי קטגוריה ועמודות מוערמות לפי חודש (לחיצה על עמודה או פלח מסננת ופותחת)
- ייצוא והעתקה ל-CSV (נפתח בעברית תקינה באקסל)
- מצב כהה ובהיר, מותאם לטלפון
- הנתונים נשמרים בדפדפן (localStorage), ללא שרת

## הרצה
```bash
npm install
npm run dev            # שרת פיתוח
npm test               # בדיקות
npm run build          # בנייה לפרודקשן (לתיקייה dist)
npm run build:artifact # קובץ HTML יחיד לפרסום כ-Artifact ב-claude.ai (dist/expense-tracker.html)
```
