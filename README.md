# מעקב הוצאות

אפליקציית ווב פשוטה למעקב אחר הוצאות אישיות, בעברית.

## פיצ'רים
- שני עמודים: **הוספת הוצאה** (נפתח ראשון, עם טופס גדול ונוח) ו**סיכום והוצאות** (כל השאר). עריכת הוצאה פותחת אותה בעמוד ההוספה וחוזרת לסיכום
- הוספה, עריכה ומחיקה של הוצאות (סכום, תאריך, תיאור, וקטגוריה מרשימה נגללת), עם הודעת אישור אחרי כל הוספה
- הוצאות קבועות שחוזרות כל חודש, עם אפשרות לערוך אותן או להפסיק אותן מחודש מסוים והלאה
- תקציב חודשי כולל ולפי קטגוריה, עם פס התקדמות (ירוק, כתום מ-80%, אדום בחריגה)
- מחיקה ללא שאלת אישור, עם כפתור ביטול של 6 שניות
- חיפוש ומיון ברשימת ההוצאות
- הוספת קטגוריה משלך (שורה קטנה בעמוד הסיכום)
- תזכורת שבועית לגיבוי
- קישור תשלום (`#pay-<סכום>-<בית עסק>`) שפותח את טופס ההוספה מלא, לשימוש עם אוטומציה של אפל פיי (ראה `docs/apple-pay-shortcut.md`)
- גיבוי לקובץ (`מעקב הוצאות <תאריך>.json`) ושחזור ממנו
- תקופות: חודש, 6 חודשים או שנה (הבורר מתחת לטופס), עם משפט סיכום, השוואה לתקופה הקודמת, ממוצע חודשי והחודש היקר ביותר
- סינון לפי קטגוריה אחת או יותר, שמשפיע על הסכום, הגרפים והרשימה
- גרפים: טבעת לפי קטגוריה עם הסכום במרכז ומקרא, ועמודות מוערמות: לפי יום בתצוגת חודש, ולפי חודש (עם סכום מעל כל עמודה) ב-6 חודשים ושנה. לחיצה על עמודת חודש פותחת אותו, ולחיצה על קטגוריה מסננת
- ברשימה, בטלפון כל הוצאה מוצגת ככרטיס קטן
- מצב כהה ובהיר, מותאם לטלפון
- הנתונים נשמרים בדפדפן (localStorage), ובתוך Claude גם בענן, בשטח פרטי של המשתמש, כך שהם לא נעלמים ומופיעים בכל מכשיר

## הרצה
```bash
npm install
npm run dev            # שרת פיתוח
npm test               # בדיקות חישוב
npm run test:e2e       # בדיקות מסך בדפדפן אמיתי (מחשב וטלפון)
npm run build          # בנייה לפרודקשן (לתיקייה dist)
npm run build:artifact # קובץ HTML יחיד לפרסום כ-Artifact ב-claude.ai (dist/expense-tracker.html)
```
