## מה זה
אפליקציית ווב אישית למעקב הוצאות. ממשק בעברית מימין לשמאל, מטבע ₪, מותאמת לטלפון, במצב בהיר וכהה.
נבנתה עם React 18, Vite ו-Recharts. הנתונים נשמרים בדפדפן (localStorage), בלי שרת.

## מה האפליקציה יודעת לעשות
- **הוספה, עריכה ומחיקה** של הוצאות: סכום, תאריך, תיאור, וקטגוריה מרשימה נגללת. טופס ההוספה בראש הדף, ואחרי כל הוספה מופיעה הודעה והשורה החדשה מהבהבת.
- **הוצאות קבועות** שחוזרות כל חודש, באותו יום בחודש. אפשר לערוך אותן או להפסיק אותן מחודש מסוים והלאה, וחודשים קודמים נשארים כמו שהיו.
- **תקציב** חודשי כולל ולפי קטגוריה, עם פס התקדמות.
- **ביטול** של מחיקה (6 שניות), במקום שאלת אישור.
- **חיפוש ומיון** ברשימה.
- **גיבוי ושחזור** לקובץ בשם "מעקב הוצאות" עם התאריך.
- **תקופות:** חודש, 6 חודשים או שנה, נספרות אחורה מהחודש שנבחר. הבורר נמצא מתחת לטופס, והחצים מזיזים תקופה שלמה.
- **סיכום:** משפט פתיחה ("בחודש הזה הוצאת..."), סה"כ, פירוט לפי קטגוריה עם אחוזים, השוואה לתקופה הקודמת, ובתקופה ארוכה גם ממוצע חודשי והחודש היקר ביותר.
- **גרפים:** טבעת "לאן הלך הכסף" עם הסכום במרכז ומקרא, ועמודות מוערמות לפי חודש עם סכום מעל כל עמודה. לחיצה על עמודה פותחת את החודש, ולחיצה על קטגוריה במקרא מסננת.
- **סינון לפי קטגוריה** (אחת או יותר) שמשפיע על הסכום, הגרפים והרשימה.

קטגוריות: אוכל, תחבורה, חשבונות, בילויים, בריאות, קניות, אחר.

## החלטות שהתקבלו
- אתר React + Vite, שמירה בדפדפן, ממשק בעברית. פיצ'רים ראשונים: ניהול הוצאות, קטגוריות, סיכום וגרפים, CSV.
- הקטגוריה "דיור" הוסרה. הוצאות ישנות ששמרו אותה מוצגות תחת "אחר".
- צבעים: עברו מצבעוני לפלטה "גברית" יותר: כחול נייבי, כחול פלדה וטורקיז, עם ענבר להדגשה.
- הסינון חל על הנתונים לפני כל חישוב, כך שהסכום, הגרפים והרשימה תמיד מסכימים.
- הוצאה קבועה לא ניתנת לעריכה. כשהסכום משתנה, מפסיקים אותה ומוסיפים חדשה.

## מגבלות ידועות
- **הנתונים בדפדפן אחד בלבד.** בטלפון ובמחשב יהיו רישומים נפרדים, וניקוי נתוני גלישה ימחק אותם.
- **בתוך עמוד ה-Artifact** חלון אישור של הדפדפן לא נפתח, ולכן האישור למחיקה מופיע בתוך השורה. ייצוא CSV הוסר, כי הורדת קבצים לא עובדת שם.
- חבילת הקוד גדולה (כ-545KB) וטוענת לאט יותר מהנדרש.

## איך מריצים ובונים
```bash
npm install
npm run dev             # שרת פיתוח
npm test                # בדיקות חישוב
npm run test:e2e        # בדיקות מסך בדפדפן אמיתי
npm run build           # בנייה לפרודקשן
npm run build:artifact  # קובץ HTML יחיד לפרסום ב-claude.ai (dist/expense-tracker.html)
```
כדי לעדכן את העמוד המפורסם: להריץ `npm run build:artifact` ולפרסם את `dist/expense-tracker.html` שוב לאותו קישור.

## מה נשאר לעשות (לפי סדר חשיבות)
1. שמירה אוטומטית בין מכשירים (היום יש רק גיבוי ידני לקובץ).
2. הוספה מהירה של הוצאות שחוזרות.
3. קטגוריות משלך: הוספה, שינוי שם וצבע ומחיקה.
4. ייבוא קובץ מהבנק או מכרטיס אשראי, עם סיווג אוטומטי.
5. פיצול חבילת הקוד.
6. חיבור לאפל פיי: אוטומציית "טרנזקציה" באפליקציית "קיצורים" באייפון שפותחת קישור עם הסכום ושם בית העסק. דורש אתר רגיל (לא Artifact), ולא בטוח שזמין עם כרטיסים ישראליים.

## איך נבנה (לפי סדר השיחה)
1. תכנון ובחירת טכנולוגיה, ובניית הגרסה הראשונה.
2. פרסום כ-Artifact והתאמה לגבלות שלו (אישור מחיקה, העתקת CSV, צבעים לפי מצב בהיר וכהה).
3. עיצוב צבעוני יותר, ואז פלטה "גברית" יותר.
4. הסרת "דיור" והוספת הוצאות קבועות.
5. תקופות (חודש, 6 חודשים, שנה), סינון לפי קטגוריה וגרף מוערם.
6. העברת טופס ההוספה לראש הדף.
7. תיעוד בריפו וסקריפט בנייה לעמוד המפורסם.
8. הסרת ייצוא ה-CSV, בורר התקופה מתחת לטופס, גרפים ברורים יותר (טבעת עם מקרא, סכומים מעל העמודות), הודעות אישור, ורשימה ככרטיסים בטלפון.
9. תיקוני באגים מהטלפון: הוצאה שנוספה בקטגוריה שהסינון מסתיר (הסינון מתאפס עכשיו, ומוצגת הודעה), שדה סכום סלחני עם הודעת שגיאה גלויה, תיבת מידע לבנה בעוגה (עוצבה מחדש), וגרף חודשי שנקרא "6 החודשים האחרונים" בתצוגת חודש (הוא מציג עכשיו הוצאות לפי יום).
10. עיצוב מרוסן יותר אחרי שהמסך נראה ילדותי: הסרת האייקונים והשיפועים, כותרת וכפתורים בכחול אחיד, ובורר תקופה חדש (פקד מקטעים ופקד חודש נקיים).
11. ביטול מחיקה, תקציבים, עריכת הוצאה קבועה, חיפוש ומיון, וגיבוי ושחזור לקובץ.
